# Blinking LEDs with Push Button Toggle

## Components
- Arduino Uno
- 4 LEDs (Red, Orange, Green, Blue)
- 4 x 220Ω resistors
- 1 x Push button
- 1 x 10kΩ resistor
- Breadboard + jumper wires

## How it works
Press the button once to start blinking all 4 LEDs.
Press again to stop.

## Pin connections
| LED    | Pin |
|--------|-----|
| Red    | 13  |
| Orange | 12  |
| Green  | 11  |
| Blue   | 10  |
| Button | 2   |
